# homebrew-tap

A Homebrew cask for [github-nippou](https://github.com/masutaka/github-nippou)

## Installation

    $ brew install --cask masutaka/tap/github-nippou

## No maintenance required

Whenever a new release is made on [github-nippou](https://github.com/masutaka/github-nippou), the cask file(s) in this repository is automatically updated.
